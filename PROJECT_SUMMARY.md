# PulseTracker – Asset Management System

## Current Version: v5.5

### Recent Changes (v5.5)
-   **Official Name Rebranding**: Rebranded the application to "PulseTracker – Asset Management System" across all UI headers, window titles, and the splash screen.
-   **Enhanced Professional Branding**: Reinforced the "prim and proper" business facade for the default operating mode.
-   **Consistency Check**: Ensured the rebranding is reflected in all asset details and "Add to Fleet" dialogs.

### Version History
-   **v5.4**: Professional Messaging Enforcement (attitude suppressed until Easter Egg). Restored Analytics Pie Charts for Individual and Company owners.
-   **v5.3**: Restored "Add to Fleet" layout, optimized default window sizes (1200x800), and fixed responsive scaling issues.
-   **v5.2**: Fixed Python-style comments (#) inside SQL strings that caused database initialization errors.
-   **v5.1**: Intensified Rift Effect (visual glitching) and added Ship Momentum Physics to the Asteroids game.
-   **v4.0**: Initial specialized Asset Tracking system for industrial/mining sectors.

### Core Features
-   **Fleet Asset Tracking**: Comprehensive database for industrial equipment with attachment support.
-   **Dynamic Analytics**: Visual distribution of assets with real-time pie charts.
-   **THE VOID**: Secret Asteroids game with ship momentum and scoring.
-   **Dual-Identity System**: Professional Asset Management interface that transforms into a "Tired Technician" theme upon unlocking.
